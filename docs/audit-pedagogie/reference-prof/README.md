# Comparaison avec le cours de référence d'un professeur (27/11/2026)

L'utilisateur a fourni un cours complet de 2ᵉ Bac SP (semestre 1, physique et chimie) d'un professeur, « pour comparer
et se référer ». Le document n'est pas dans le dépôt (dépôt public) : chaque fichier ici résume, avec nos mots, le plan du
professeur, la place de ses rappels, les différences d'ordre avec notre cours et les corrections recommandées, croisées
avec `../ordre-des-notions/<deck>.md`.

- Un fichier par cours de physique-chimie (`phys_ch1` à `phys_ch13`).
- `modulation_AM_manquant.md` : chapitre au programme (cadre de référence) sans cours chez nous — plan, ordre des
  notions, prérequis, méthodes du national, animations à prévoir.
- Le professeur confirme la plupart des corrections de l'audit et n'en contredit aucune ; quelques points ajustés sont
  notés dans chaque fichier (« le prof confirme / nuance »). Ce qui est hors du cadre de référence (régime critique,
  filtres passe-bas/passe-haut) n'est pas à ajouter.
