## Le cahier idéal (ordre du cours en ligne)


### Ouverture — une information transmise


### I. L'information génétique est dans le noyau

- Les caractères héréditaires passent des parents à l'enfant par la cellule-œuf.
- Rappel : cellule = membrane plasmique + cytoplasme + noyau (le noyau commande la cellule).
- 1. Mérotomie de l'amibe : seul le fragment avec noyau survit, grandit et se divise.
- Donc le noyau est indispensable à la vie de la cellule et à sa division.
- 2. Acétabulaire : algue unicellulaire (4 à 6 cm) : chapeau, tige, rhizoïde (avec le noyau).
- Section : seul le rhizoïde (noyau) régénère → simple hypothèse : le noyau commande.
- Greffe croisée : le chapeau suit le noyau → l'information génétique est dans le noyau.
- 3. Gurdon : noyau de têtard albinos + ovule sans noyau (UV) → grenouille albinos.
- Définition : l'information génétique est l'ensemble des instructions, portées par le noyau, qui commandent les caractères héréditaires.

### II. Dans le noyau : chromatine et chromosomes

- 1. Cellule humaine : 46 chromosomes = 23 paires d'homologues (un de la mère, un du père).
- 2n = 46 (n = 23) : la cellule est diploïde ; un chromosome = un long fil d'ADN enroulé.
- 2. Mitose : une cellule → deux cellules filles identiques (chromosomes copiés, puis partagés).
- Par mitoses successives, la cellule-œuf donne toutes les cellules du corps (46 chromosomes).
- 3. Noyau en interphase : enveloppe nucléaire à pores, nucléoplasme, nucléole, chromatine.
- Chromatine = nucléofilaments ; nucléosome = ADN + histones (aspect en collier de perles).
- 4. Feulgen (colore l'ADN) : noyaux et chromosomes rouges ; sans histones : charpente + ADN.
- Donc chromosome = ADN + protéines ; en division, la chromatine se condense en chromosomes.
- 5. 1 chromatide = 1 ADN ; après réplication : 2 chromatides reliées par le centromère.
- *Dessin : Chromosome dont on a retiré les histones* — Il reste une charpente de protéines qui garde la forme du chromosome, entourée d'un très long fil d'ADN : chromosome = ADN + protéines.
- *Dessin : Chromosome à une ou deux chromatides* — Après la réplication de l'ADN, le chromosome a deux chromatides identiques reliées par le centromère : 1 chromatide = 1 molécule d'ADN.

### III. Le cycle cellulaire et la quantité d'ADN

- 1. Définition : le cycle cellulaire est la vie d'une cellule entre deux divisions successives.
- Cycle = G1 + S + G2 + M ; interphase = G1 (croissance) + S (réplication) + G2 (croissance).
- 2. Quantité d'ADN : q en G1 ; q → 2q en S (réplication) ; 2q en G2 ; q en fin de mitose.
- Donc chaque cellule fille reçoit q : la même information que la cellule mère.
- Attention : l'interphase n'est pas un repos ; la réplication n'a lieu qu'en phase S.
- *Dessin : La quantité d'ADN au cours du cycle* — q = 3 UA en G1 ; de 8 à 14 h (phase S) la réplication double l'ADN : 2q = 6 UA en G2 ; de 19 à 20 h (mitose), retour à q dans chaque cellule fille.
- 3. Aspect du chromosome : G1 une chromatide ; S yeux de réplication ; G2 deux chromatides.
- Mitose : condensation puis séparation des chromatides. Attention : fin de S = plus d'yeux.
- Méthode (courbe) : 1) lire les axes ; 2) décrire chaque phase avec les valeurs ; 3) expliquer.
- 4. Durée du cycle : 2,5·10³ → 5·10³ → 10·10³ en 40 h = 2 doublements = 2 cycles → 20 h.
- Durée d'une phase = (% de cellules dans la phase / 100) × durée du cycle.
- Exemple : G1 = 0,45 × 20 h = 9 h ; G2 = 4 h ; M = 1 h ; S = 20 − (9 + 4 + 1) = 6 h.
- *Dessin : Le chromosome au cours du cycle* — G1 : une chromatide ; S : yeux de réplication ; G2 : deux chromatides reliées par le centromère ; M : chromosome condensé, puis chromatides séparées.

### IV. La mitose

- Définition : la mitose est une division cellulaire qui donne deux cellules filles génétiquement identiques à la cellule mère.
- 1. Prophase : condensation (2 chromatides) ; enveloppe et nucléole disparaissent ; fuseau.
- 2. Métaphase : chromosomes alignés par leur centromère sur la plaque équatoriale.
- 3. Anaphase : clivage du centromère ; les chromatides sœurs migrent vers les pôles opposés.
- 4. Télophase : étranglement ; décondensation ; enveloppe et nucléole reviennent ; plus de fuseau.
- *Dessin : Métaphase d'une cellule animale (2n = 4)* — Chromosomes très condensés, à deux chromatides, alignés par leur centromère sur la plaque équatoriale ; fuseau : fibres polaires et fibres chromosomiques.
- *Dessin : Télophase d'une cellule animale (2n = 4)* — Étranglement au milieu ; les chromosomes se décondensent ; l'enveloppe nucléaire et le nucléole réapparaissent ; le fuseau a disparu : deux noyaux, puis deux cellules filles.
- 5. Cellule végétale : calottes polaires (pas d'asters) ; nouvelle paroi (pas d'étranglement).
- Attention : centrosome (d'où partent les asters) ≠ centromère (relie les deux chromatides).
- Méthode (identifier) : nom de la phase + « car » + critère vu (plaque équatoriale → métaphase).
- Ordre : interphase → prophase → métaphase → anaphase → télophase.
- Méthode (schéma) : titre + 2n + même nombre de chromatides à chaque pôle + légendes.
- Attention : en mitose, ce sont les chromatides sœurs qui se séparent, pas les homologues.
- *Dessin : Anaphase d'une cellule animale (2n = 4)* — Le centromère s'est clivé : les chromatides sœurs migrent vers les pôles opposés, 4 chromatides à chaque pôle ; fibres du fuseau entre les deux asters ; membrane plasmique.
- *Dessin : Télophase d'une cellule végétale (2n = 4)* — Pas d'asters ni d'étranglement, car la cellule a une paroi : une nouvelle paroi se forme au milieu entre les deux noyaux.

### V. L'ADN, support de l'information génétique

- 1. Griffith (1928) : pneumocoques S (capsule, virulents) et R (sans capsule, non virulents).
- Remarque : S = smooth (colonies lisses) ; R = rough (colonies rugueuses).
- Expérience 1 : S vivants → la souris meurt.
- Expérience 2 : R vivants → la souris vit (pas de pneumocoques dans son sang).
- Expérience 3 : S tués par la chaleur → la souris vit (pas de pneumocoques dans son sang).
- Expérience 4 : R vivants + S tués → la souris meurt ; son sang contient des S vivants.
- Donc des R ont été transformés en S par un principe transformant venu des S tués.
- 2. Avery (1944) : S tués + enzyme + R vivants ; protéase ou ribonucléase → souris morte.
- Désoxyribonucléase → souris vivante : sans ADN, pas de transformation ; le principe = l'ADN.
- 3. Transformation : un fragment d'ADN de S entre dans R, s'intègre à son ADN → capsule.
- Bactéries filles S : l'ADN est le support chimique de l'information génétique.
- *Dessin : La transformation bactérienne* — Un fragment d'ADN de S entre dans une bactérie R et s'intègre à son ADN ; R fabrique une capsule et devient S ; ses bactéries filles sont S : le caractère est héréditaire.

### VI. La molécule d'ADN

- 1. Nucléotide = acide phosphorique + désoxyribose + base azotée (A, T, C ou G).
- A (adénine), G (guanine) : puriques ; T (thymine), C (cytosine) : pyrimidiques.
- ADN (acide désoxyribonucléique) = polynucléotide : les nucléotides s'enchaînent en brin.
- 2. Chargaff : A/T = 1 et C/G = 1 → A s'associe à T, C à G : complémentarité des bases.
- (A + G)/(T + C) = 1 (propre à l'ADN) ; (A + T)/(G + C) varie : caractéristique de l'espèce.
- 3. Les deux brins sont antiparallèles (tête-bêche) : l'un 5' → 3', l'autre 3' → 5'.
- *Dessin : Un nucléotide d'ADN* — Nucléotide = acide phosphorique + désoxyribose + base azotée (A rouge, T jaune, C bleu, G vert) ; d'un nucléotide à l'autre, seule la base change.
- 4. Double hélice (Watson et Crick, 1953) : A = T (2 liaisons hydrogène), C ≡ G (3).
- 0,34 nm entre deux paires de bases ; 3,4 nm par tour (10 paires) ; diamètre 2 nm.
- Méthode (brin complémentaire) : 1) A ↔ T et C ↔ G ; 2) inverser les extrémités 5' et 3'.
- Exemple : 5' ATCGGA 3' → brin complémentaire 3' TAGCCT 5'.
- Attention : jamais A–G ni C–T ; écrire d'abord les extrémités, tête-bêche.
- *Dessin : Deux brins complémentaires et antiparallèles* — A en face de T (2 liaisons hydrogène), C en face de G (3) ; les flèches donnent le sens 5' → 3' : 5' ATC… 3' en face de 3' TAG… 5'.

### VII. La réplication semi-conservative de l'ADN

- 1. Trois hypothèses : conservative, semi-conservative, dispersive.
- Semi-conservative : chaque molécule fille = un brin ancien + un brin nouveau.
- 2. Meselson et Stahl (1958) : E. coli sur ¹⁵N (ADN lourd), puis sur ¹⁴N ; centrifugation.
- Témoins : ADN léger 1,710 g·cm⁻³ ; ADN lourd 1,724 g·cm⁻³ (le lourd descend plus bas).
- G1 : une bande, d = (1,710 + 1,724)/2 = 1,717 g·cm⁻³ : ADN hybride → conservative rejetée.
- G2 : 2 hybrides + 2 légères (50 % / 50 %) : deux bandes égales → dispersive rejetée.
- G3 : 2 hybrides (25 %) et 6 légères (75 %) ; la bande hybride ne disparaît jamais.
- Donc réplication semi-conservative : chaque molécule fille garde un brin de la molécule mère.
- Méthode : 1) bandes et densités ; 2) témoins ; 3) tester chaque hypothèse ; 4) conclure.
- Attention : en G1 on ne rejette que la conservative ; la dispersive n'est rejetée qu'en G2.
- *Dessin : Meselson et Stahl : les bandes d'ADN* — G0 : ADN lourd ; G1 : une bande hybride (1,717 g·cm⁻³) ; G2 : hybride + légère, moitié-moitié : la réplication est semi-conservative.
- 3. Taylor : thymidine radioactive (entre dans l'ADN à la réplication) ; autoradiographie.
- 1er cycle (radioactif) : chaque ADN = brin ancien + brin radioactif → 2 chromatides marquées.
- 2e cycle (milieu normal) : une chromatide marquée sur deux → réplication semi-conservative.
- 4. Mécanisme (phase S) : yeux de réplication, par rupture des liaisons hydrogène.
- Deux fourches avancent en sens opposés ; chaque brin ancien sert de modèle (matrice).
- *Dessin : Thymidine radioactive : les brins d'ADN* — Bleu : brin ancien ; rouge : brin radioactif (1er cycle, milieu radioactif) ; blanc : brin nouveau non radioactif (2e cycle, milieu normal) : une chromatide marquée sur deux.
- *Dessin : Un œil de réplication* — Les liaisons hydrogène se rompent, les deux brins anciens (bleu) se séparent et chacun sert de modèle à un brin nouveau (orange) ; les deux fourches avancent en sens opposés.
- L'ADN polymérase assemble les nucléotides libres par complémentarité (A–T, C–G).
- Attention : le brin nouveau s'allonge toujours dans le sens 5' → 3'.
- Fin de S : les yeux fusionnent → 2 molécules identiques (1 brin ancien + 1 brin nouveau).
- Ces deux molécules d'ADN sont les deux chromatides du chromosome.
- 5. Réplication (q → 2q) puis mitose (q par cellule fille) conservent l'information.
- *Dessin : Une molécule mère, deux molécules filles* — Chaque molécule fille garde un brin ancien (bleu) et reçoit un brin nouveau (orange), allongé de 5' vers 3' (flèche) : les deux molécules sont identiques.

- Les deux définitions (information génétique, mitose) sont gardées mot pour mot : 135 et 125 caractères, elles
  passent sur deux lignes à l'écran.
- En attente, `ig_s2_b3` contient la fin du II (chromatides) et le début du III : l'application écrit le titre du III
  au-dessus de tout le bloc, d'où « 5. (fin du II) » sur la première ligne.
