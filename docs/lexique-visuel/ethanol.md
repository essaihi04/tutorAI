# Éthanol

Fermentation alcoolique : le 3e carbone de l'acide pyruvique part en CO₂ ; restent **2 billes jaunes + 2 hydrogènes blancs.**

## Les formes

| Forme | Dessin | Couleurs | Étiquette | Quand l'utiliser | Appel |
|---|---|---|---|---|---|
| billes (défaut) | 2 billes jaunes liées + 2 H blancs entre elles | C jaune, H blanc | « éthanol (2 C) » | animations | `Lexique.ethanol(ctx, x, y, o)` |
| semi-développée | CH₃–CH₂OH | craie | — | équation | `{ forme: 'semi_developpee' }` |
| brute | C₂H₆O | craie | — | bilan | `{ forme: 'brute' }` |

## Où il apparaît

SVT ch1 : fermentations.html (voie alcoolique).

## Pourquoi ce choix

Dessiné à partir de l'acide pyruvique.

Module : `frontend/public/media/simulations/shared/lexique/lexique.js` (`window.Lexique`). Index et code des couleurs : [README](README.md).
