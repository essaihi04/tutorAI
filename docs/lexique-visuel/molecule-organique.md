# Molécule organique (RH₂)

Une molécule organique non nommée : **chaîne droite de n carbones jaunes (4 par défaut, jamais 6 : 6 = le glucose).**

## Les formes

| Forme | Dessin | Couleurs | Étiquette | Quand l'utiliser | Appel |
|---|---|---|---|---|---|
| billes | chaîne droite | C jaune | « molécule organique » | oxydoréduction | `Lexique.moleculeOrganique(ctx, x, y, { n })` |

## Où il apparaît

SVT ch1 : taxi.html.

## Pourquoi ce choix

Distinct du glucose, même code de couleur.

Module : `frontend/public/media/simulations/shared/lexique/lexique.js` (`window.Lexique`). Index et code des couleurs : [README](README.md).
