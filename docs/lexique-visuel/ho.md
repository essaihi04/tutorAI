# Ion hydroxyde HO⁻

**O rouge + H blanc dans un anneau bleu ciel (la charge −).**

## Les formes

| Forme | Dessin | Couleurs | Étiquette | Quand l'utiliser | Appel |
|---|---|---|---|---|---|
| billes | O + H + anneau bleu ciel et « − » | O rouge, H blanc, anneau [96,200,250] | « HO⁻ » à la craie bleue | chimie | `Lexique.ho(ctx, x, y, o)` |

## Où il apparaît

Chimie : modèle O+H (commun.js), sphère bleue (ab/exploiter), sphère ROUGE (cin/conductimetrie, tds/dilution).

## Pourquoi ce choix

Code atomique + couleur de la charge négative (celle de l'électron).

Module : `frontend/public/media/simulations/shared/lexique/lexique.js` (`window.Lexique`). Index et code des couleurs : [README](README.md).
