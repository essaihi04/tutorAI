## Définitions telles qu'écrites
- **Isotopes** : « Un isotope est l'ensemble des noyaux ayant même numéro atomique Z » (ex. ¹²₆C, ¹³₆C, ¹⁴₆C). ⚠ incomplète : il manque « et des nombres de nucléons A différents ».
- **Désintégration** : transformation nucléaire **naturelle, spontanée et aléatoire** au cours de laquelle un noyau radioactif (instable) se désintègre en donnant un noyau plus stable, avec émission d'une particule et parfois d'un rayonnement. Schéma sous la définition : ᴬ_Z X → ᴬ'_Z' Y + ᴬ''_Z'' P, avec en dessous « noyau radioactif / noyau père / noyau instable » et « noyau fils / noyau plus stable » + « particule ».
- **Lois de Soddy** : au cours d'une transformation nucléaire il y a conservation du nombre de masse (A = A₁ + A₂) et conservation du nombre de charge (Z = Z₁ + Z₂).
- **Types** (encadré rouge, flèches) : β⁻ : ⁰₋₁e électron ; β⁺ : ⁰₊₁e positon ; α : ⁴₂He hélium ; γ : rayonnement électromagnétique.
- **Désexcitation** (γ) : un noyau fils peut naître excité (noyau avec « excès d'énergie », noté Y*) ; il revient à son état fondamental en émettant γ.
- **Liste de la loi de décroissance** : N₀ = nombre de noyaux père à t = 0 ; N = nombre de noyaux père **restants** = { nombre de noyaux père **non désintégrés** } ; N_d = nombre de noyaux père désintégrés ; N_fils = nombre de noyaux fils formés.
- **λ** : la constante radioactive (unité : temps⁻¹). **τ** : la constante de temps (s).
- **t½ — temps de demi-vie** : « c'est la durée nécessaire pour que la moitié des noyaux père soit désintégrés » ; traduite aussitôt par N(t½) = N₀/2 (encadré rouge).
- Pas d'activité ni de becquerel dans cette partie.

## Formules telles qu'écrites (et dites)
- Noyau : **A = Z + N ⇒ N = A − Z** (encadré).
- β⁻ : ᴬ_Z X → ᴬ_(Z+1) Y + ⁰₋₁e (Z+1 souligné) ; « excès de neutrons » ; mécanisme encadré en nuage : ¹₀n → ¹₁p + ⁰₋₁e.
- β⁺ : ᴬ_Z X → ᴬ_(Z−1) Y + ⁰₊₁e ; « excès de protons » ; mécanisme : ¹₁p → ¹₀n + ⁰₊₁e.
- α : ᴬ_Z X → ᴬ⁻⁴_(Z−2) Y + ⁴₂He ; « pour les noyaux lourds A > 195 » corrigé en **A > 200**.
- γ : ¹⁶₈O* → ¹⁶₈O + γ ; **E_γ = h·ν** (E en J, ν fréquence en Hz), h = 6,63·10⁻³⁴ SI « constante de Planck ».
- Rappel mathématique (tableau 1, deux colonnes) : ln : D = ]0 ; +∞[, ln 1 = 0, ln(A/B) = ln A − ln B, ln(A·B) = ln A + ln B, ln(1/A) = −ln A, ln xⁿ = n·ln x ; exp : e⁰ = 1, D = ℝ, e^A/e^B = e^(A−B), e^A·e^B = e^(A+B), e^(−x) = 1/eˣ ; puis en rouge avec un triangle « attention » : **ln(eˣ) = x**, **e^(ln x) = x**, et ln(e) = 1 dans une bulle.
- Tableau « Résultats » : e⁰ = 1, e^(+∞) = +∞, e^(−∞) = 0 écrits en tête, avant les courbes.
- **① N = N₀·e^(−λt)** (avec « N₀ > N » à côté) ; **② N₀ = N + N_d** ; **③ N_d = N₀ − N = N₀ − N₀e^(−λt) = N₀(1 − e^(−λt))** ; **④ λ = 1/τ** (numéros entourés). Écriture : λ en lettre grecque, point de multiplication « N₀ · e^(−λt) ».
- Exemple : U → Pb + α (U marqué « Père ») : N(U) = N₀(U)·e^(−λt) ; N_d(U) = N(Pb) = N₀(U)(1 − e^(−λt)). Il insiste à l'oral : le N et le λ sont ceux du **père**, pas du fils.
- **Démonstration de t½** (écrite ligne par ligne sous la courbe) : N(t) = N₀e^(−λt) → N(t½) = N₀e^(−λt½) → N₀/2 = N₀e^(−λt½) (N₀ barré) → 1/2 = e^(−λt½) → ln(1/2) = ln e^(−λt½) → −ln2 = −λt½ → ln2 = λt½ → **t½ = ln2/λ** (encadré en nuage rouge). Notation écrite : **t₁/₂** (indice « 1/2 »), dite « t un demi ».
- **N(t = τ) = N₀e^(−λτ) = N₀e^(−1) = 0,37·N₀** (encadré) ; à l'oral : on remplace λ par 1/τ, τ se simplifie, il reste e⁻¹.
- **N_d(t = τ) = N₀(1 − e^(−1)) = 0,63·N₀**.

## Faux, imprécis ou à ne pas répéter
- **Définition des isotopes incomplète** (même Z sans dire « A différent »).
- **« α pour A > 200 »** (195 puis 200) : seuil arbitraire ; dire « surtout les noyaux lourds ».
- **Noyau qui « vieillit » / « meurt »** : faux physiquement (un noyau ne vieillit pas ; sa probabilité de se désintégrer ne dépend pas de son âge). À remplacer par « chaque noyau a la même chance de se désintégrer à chaque instant, jeune ou vieux ».
- « Droite de stabilité » pour N = Z : seuls les noyaux légers stables sont près de N = Z ; la vallée s'en écarte.
- N_d = N_fils n'est vrai que si le fils est stable et unique (pas de famille) ; il ne le précise pas.
- E_γ = h·ν : hors du strict besoin du chapitre (relève du cours lumière), pas faux.
- Rien sur capture électronique, quarks, interaction forte.
