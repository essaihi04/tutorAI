## Définitions telles qu'écrites (traduites ; tout est en arabe au tableau)
- **Noyau** : bulle partagée « Z | N », Z → « nombre de protons », N → « nombre de neutrons » ; A → « nombre de nucléons » (عدد النويات) ; A = Z + N encadré.
- **Isotopes** (النظائر, titre dans une bulle) : on appelle isotopes les nucléides qui ont le même nombre Z mais diffèrent par A (ou N) ; ils ont le même symbole chimique.
- **Désintégrations** : chaque équation porte trois bulles sous ses termes : **noyau père (instable)**, **noyau fils**, **particule émise** (الدقيقة المنبعثة), et le nom de la particule sous la bulle (هيليوم / إلكترون ⊖ / بوزيترون). Pas de phrase-définition de la radioactivité visible dans les images, ni de « spontanée, aléatoire, inévitable ».
- **γ** : rayonnement γ = ondes électromagnétiques ; l'astérisque est expliqué en bas de tableau : « * = excitation » (إثارة أو إهاجة).
- **Lois de Soddy** (حسب قوانين صودي) : « conservation du nombre A », « conservation du nombre Z », appliquées ligne par ligne sur l'exemple (234 = A + 4 → A = 230…). Pas de forme générale encadrée.
- **N(t)** : trois bulles sous la formule : N(t) « nombre de noyaux restants » (المتبقية), N₀ « nombre de noyaux initiaux à t = 0 », λ « constante radioactive (s⁻¹) ».
- **Activité** : « loi ② : l'activité », Bq = **becquerel : nombre de désintégrations par seconde**. Lettre **a minuscule**, a₀.
- **Constante de temps τ** (ثابتة الزمن τ) : pas de phrase-définition ; définie par ses deux lectures graphiques et τ = 1/λ.
- **Demi-vie t½** (عمر النصف) : « c'est la durée nécessaire à la désintégration de la moitié de l'échantillon initial ».

## Formules telles qu'écrites
- **N(t) = N₀·e^(−λ·t)** (point de multiplication écrit avant e et entre λ et t), encadrée dans une bulle. Pas d'indice r (N(t), pas Nr).
- Activité : **a(t) = a₀·e^(−λt)  (Bq)** et **a(t) = λ·N(t)**, numérotées ① et ② ; il les étiquette « en fonction du temps » et « en fonction de N ». **Pas de a = −dN/dt, pas de dN/dt = −λN, pas de ΔN/Δt** : les deux lois sont données.
- **τ = 1/λ**, encadré (« théoriquement »). Graphiquement : (a) **N(τ) = 0,37·N₀** puis projection sur l'axe des temps ; (b) **la tangente à l'origine coupe l'axe des abscisses en t = τ** (écrit : intersection de la tangente avec l'axe des abscisses). Exemple : courbe N₀ = 100, 0,37 × 100 = 37, projection → **τ = 10 s** ; la tangente à l'origine est tracée en rouge sur la même courbe et coupe l'axe au même point (« méthode 1 : la tangente », « méthode 2 : 0,37·N₀ »). Même courbe pour t½ : N(t½) = N₀/2 = 100/2 = 50, projection sur l'axe des temps (≈ 7 s, valeur peu lisible).
- **t½** écrit **t₁/₂** (fraction ½ en indice). Graphiquement **N(t½) = N₀/2** (encadré) ; théoriquement **t½ = ln(2)/λ** (encadré). La valeur 0,69 n'est pas écrite. La formule N₀/2ⁿ n'apparaît pas.
- **Démonstration de t½** (titre « البرهان », écrite à droite, ligne par ligne, vérifiée par la passe serrée) : « on sait que N(t) = N₀·e^(−λ·t) » ; « pour t = t½ » : N(t½) = N₀·e^(−λ·t½) ; N(t½) remplacé par N₀/2 (flèche) ; N₀/2 = N₀·e^(−λt½), **N₀ barré des deux côtés** ; 1/2 = e^(−λt½) ; **on inverse les deux membres** (flèche « المقلوب », l'inverse) : 2 = e^(+λt½) ; ln(2) = ln(e^(+λt½)) ; ln(2) = λ·t½ ; **t½ = ln(2)/λ** encadré. Pendant ce temps, un encadré de rappel à droite : **ln(e) = 1** et **e^(+x) = 1/e^(−x)**. Cette inversion évite le ln(1/2) = −ln2 et les signes moins : c'est la version la plus simple vue dans le lot.
- **Datation** (V, « l'âge ou la datation », t cerclé) : deux bulles « a(t) = a₀·e^(−λ(t)) » et « N(t) = N₀·e^(−λ(t)) » avec le t entouré (c'est l'inconnue). Démonstration avec la même méthode : N(t)/N₀ = e^(−λt) ; **inverse** (« المقلوب ») N₀/N(t) = e^(+λt) ; ln(N₀/N(t)) = ln(e^(+λt)) ; ln(N₀/N(t)) = λ·t ⇒ **t = ln(N₀/N(t))/λ** (encadré) ; puis par analogie **t = ln(a₀/a(t))/λ** (encadré), avec « λ ??? » sous le λ ; en dessous t½ = ln(2)/λ ⇒ **λ = ln(2)/t½** (encadré, flèche vers le λ des formules de t, petit triangle « ! »). Écriture recommandée : la fraction N₀/N(t) (ou a₀/a) toujours mise **> 1** pour que t soit positif sans signe moins.
- **Masse** : m/M = N/N_A, d'où N = m·N_A/M (le passage m(t) = m₀e^(−λt) n'est pas visible).
