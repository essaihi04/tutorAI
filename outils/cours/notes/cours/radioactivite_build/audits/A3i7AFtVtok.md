## Définitions telles qu'écrites (au tableau, en français)
- **Proton** : « positif », q = +1,6×10⁻¹⁹ C, r = 1,2 fm, m = 1,6727×10⁻²⁷ kg. **Neutron** : « neutre », q = 0 C, r = 1,2 fm = 1,2×10⁻¹⁵ m, m = 1,6749×10⁻²⁷ kg. Il note les grandeurs du proton avec l'**indice Z** (q_Z, r_Z, m_Z) et celles du neutron avec l'**indice N** (q_N, r_N, m_N) ; il écrit puis barre m_Z = m_N (les masses sont voisines mais pas égales).
- **A** : « le nombre de masse A », « le nombre de nucléons », et un troisième nom mal lisible (vraisemblablement « la masse molaire »). **Z** : « le numéro atomique », « le nombre de protons », « le nombre de charge ». Il relie les deux listes par une grande croix.
- **Nucléons** : arbre nucléons → protons / neutrons, puis **A = Z + N**, **N = A − Z**.
- Pas de définition écrite d'**isotope** ni de **nucléide** dans les images de cette partie.
- **Transformation nucléaire (radioactivité)** : « est une transformation au cours de laquelle un noyau instable devient **plus stable** (souligné), avec l'émission d'une particule ou d'énergie électromagnétique ; cette transformation est spontanée, aléatoire, indépendante de la pression et de la température ».
- **Noyau père** : écrit sous X avec deux synonymes, « noyau instable », « noyau radioactif », « père ». **Noyau fils** : « noyau plus stable », « noyau fils » ; la troisième espèce est la « particule émise ».
- **Spontanée** : « le noyau fait la désintégration sans sollicitation extérieure ». **Aléatoire** : « qu'on ne peut pas prévoir à l'avance le temps de la radioactivité ». (« Inévitable » n'est pas écrit.)
- **α** : « la radioactivité α (⁴₂He) ». **β⁻** : particule ⁰₋₁e. **β⁺** : ⁰₊₁e, « positon » écrit dessous. **γ** : titre « la radioactivité γ », mais présentée comme ce qui **suit** α, β⁻ ou β⁺ (accolade α/β⁻/β⁺ ⇒ γ) ; « **Excité** : excès en énergie électromagnétique », Y* noté avec une étoile.
- **Lois de Soddy** : « les lois de Soddy : lois de conservation » ; « 1ère loi : conservation du nombre de masse A » ; « 2ème loi : conservation du numéro atomique Z ».

## Formules telles qu'écrites
- Composition : A = 238, Z = 92, **N = A − Z = 238 − 92 = 146** ; ⁴₂He : A = 4, Z = 2, N = 4 − 2 = 2.
- Stabilité, en deux lignes : « Noyau instable ← F.R > F.N » avec une accolade vers « N > Z » ou « Z > N » ; « Noyau stable ← F.R < F.N » vers « N = Z », « N ≈ Z ». (F.R = force de répulsion, F.N = force nucléaire.)
- **α**, toujours dans le même ordre : équation à inconnues ᴬ_Z X → ᴬ'_Z' Y + ⁴₂He ; puis **A = A' + 4 ⇒ A' = A − 4** ; **Z = Z' + 2 ⇒ Z' = Z − 2** ; puis l'équation finale **encadrée** ᴬ_Z X → ᴬ⁻⁴_Z₋₂ Y + ⁴₂He.
- Application α : « l'uranium ²³⁸₉₂U est radioactif α, il donne le ᴬ_Z Th » ; 238 = A + 4 ⇒ A = 238 − 4 = 234 ; 92 = Z + 2 ⇒ Z = 92 − 2 = 90 ; encadré ²³⁸₉₂U → ²³⁴₉₀Th + ⁴₂He.
- **β⁻** : A = A' + 0 ⇒ A = A' ; Z = Z' − 1 ⇒ Z' = Z + 1 ; encadré ᴬ_Z X → ᴬ_Z₊₁ Y + ⁰₋₁e ; « le mécanisme : ¹₀n → ¹₁p + ⁰₋₁e ».
- **β⁺** : A = A' + 0 ⇒ A = A' ; Z = Z' + 1 ⇒ Z' = Z − 1 ; ᴬ_Z X → ᴬ_Z₋₁ Y + ⁰₊₁e ; mécanisme ¹₁p → ¹₀n + ⁰₊₁e.
- **γ** : ᴬ_Z X →(β⁺) ᴬ_Z₋₁ Y* + ⁰₊₁e, puis ᴬ_Z₋₁ Y* → ᴬ_Z₋₁ Y + γ (γ dessiné avec une petite onde).
- Notation de la particule chargée : il écrit l'indice +1 en entier (⁰₊₁e), jamais ⁰₁e.
- **Aucune** formule de décroissance (N(t), λ, t½, τ, a, dN/dt) dans cette partie.

## Diagramme N-Z / Segré
Absent. La stabilité n'est vue que par **l'équilibre des deux forces** sur ⁴₂He et par la règle N ≈ Z. Les zones α / β⁻ / β⁺ sont amenées autrement : α pour les « noyaux lourds », β⁻ pour un noyau **dessiné plein de N** (excès de neutrons), β⁺ pour un noyau **dessiné plein de Z** (excès de protons). C'est la logique du diagramme sans le diagramme.

## Exemples chiffrés et noyaux
- ²³⁸₉₂U (composition puis α → ²³⁴₉₀Th) ; ⁴₂He (composition, puis modèle du noyau stable à 2 p + 2 n).
- β⁻, β⁺, γ : **noyaux fictifs X, Y** uniquement (pas de ¹⁴C, ⁶⁰Co, ³⁰P…).
- Constantes : 1,6×10⁻¹⁹ C ; 1,2 fm ; 1,6727×10⁻²⁷ kg ; 1,6749×10⁻²⁷ kg.

## Analogies et images
- **Le noyau ⁴₂He dessiné en petit trèfle** (deux N, deux Z) avec deux flèches rouges vers l'intérieur (force nucléaire, cohésion) et deux flèches bleues vers l'extérieur (répulsion) : l'image de la stabilité comme un **bras de fer** entre deux forces.
- **Le zigzag U → X₁ → X₂ → X₃ → … → noyau stable** : une famille radioactive dessinée comme un escalier qui descend jusqu'au stable, juste après la définition (« plus stable » souligné). Il ne nomme pas « famille radioactive » au tableau.
- **Le noyau-sac de lettres** : un ovale rempli de « N N N » (trop de neutrons) → après β⁻ un des N est devenu Z ; un ovale rempli de « Z Z Z » → après β⁺ un Z est devenu N. Le mécanisme n → p + e⁻ est écrit juste en dessous du dessin.
- Les gestes : mains qui se rapprochent (force nucléaire), qui s'écartent (répulsion), qui « lancent » la particule.

## Ce sur quoi il insiste
- **L'ordre fixe de chaque type** : équation à inconnues → deux lignes de Soddy (A puis Z) avec « ⇒ » → équation finale encadrée → dessin → mécanisme. C'est la même méthode qu'on attend au national (« écrire l'équation en précisant les lois utilisées »).
- Le mot **« plus stable »** souligné dans la définition : le fils n'est pas forcément stable, il est *plus* stable (d'où le zigzag).
- Les mots exacts « spontanée » et « aléatoire », chacun avec sa phrase.
- Méthode de calcul de A et Z d'un fils inconnu, posée comme une équation (238 = A + 4 ⇒ A = 234).
- Aucun national daté cité dans les images.

## Ce qui est faux, approximatif ou hors programme
- **« Noyaux lourds A > 150 »** pour α (à ≈ 49:00) : trop bas. Un commentaire le corrige (« A > 190, pas 150 ») et un autre demande « on peut dire A > 200 ? ». Dans notre cours : α concerne surtout les **noyaux lourds (A > 200 environ)**.
- **« Noyau stable ⇔ N = Z ou N ≈ Z »** : vrai seulement pour les noyaux légers (Z < 20 environ). Les noyaux stables lourds ont N > Z (²⁰⁸Pb : 82 p, 126 n). Ne pas répéter ; dire « N ≈ Z pour les légers, N > Z pour les lourds, c'est la vallée de stabilité ».
- **« F.R > F.N ⇒ instable »** : image utile mais simpliste ; un noyau trop riche en neutrons (β⁻) n'est pas instable à cause de la répulsion entre protons. « Force nucléaire » = interaction forte, à garder qualitatif (hors programme comme notion).
- **γ « excès en énergie électromagnétique »** : maladroit ; le noyau fils est dans un état excité (excès d'énergie), et il libère cette énergie sous forme de rayonnement électromagnétique γ. γ n'est pas une « radioactivité » à part : c'est une désexcitation qui accompagne α ou β.
- Indices **q_Z, m_Z** pour le proton et **q_N, m_N** pour le neutron : notation personnelle (le manuel écrit m_p, m_n).
- Troisième nom de A (« la masse molaire » ?) : A n'est pas une masse molaire ; il est seulement *numériquement voisin* de M en g/mol.
- « Indépendante de la pression et de la température » : juste ; mais il manque « inévitable » et la notion de nucléide/isotope dans cette partie.
- Rien sur la conservation de la charge ni de l'énergie (normal à ce niveau). Pas de capture électronique ni de neutrino (bien : hors programme).
