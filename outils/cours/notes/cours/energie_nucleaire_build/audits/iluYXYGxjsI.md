## Formules telles qu'écrites
- Bandeau permanent (haut gauche) : 1 u = 1,66·10⁻²⁷ kg ; 1 eV = 1,6·10⁻¹⁹ J ; 1 MeV = 1,6·10⁻¹³ J ; 1 u = 931,5 MeV/c² (puis réécrit **1 u·c² = 931,5 MeV**) ; m(p) = 1,0087 u (sic, valeur du neutron) ; c = 3·10⁸ m·s⁻¹.
- E = m·c² (encadré, ***), ΔE = Δm·c² ; système : Eᵢ = 10 J, E_f = 1 J → ΔE = E_f − Eᵢ < 0 « le système perd de l'énergie ».
- **Δm(ᴬ_ZX) = [Z·m(p) + (A−Z)·m(n)] − m(X)** (encadré). Ordre de calcul : nucléons séparés d'abord, masse du noyau ensuite. Exemple : Δm(⁴₂He) = 2·m(p) + 2·m(n) − m(He) ≈ 0,0304 u.
- **El(ᴬ_ZX) = Δm(X)·c² > 0** (encadré) ; El(He) = (0,0304 u)·c² → remplace u·c² par 931,5 MeV : El = 0,0304 × 931,5 MeV. La conversion se fait **en écrivant 1 u·c² = 931,5 MeV**, pas en passant par les kg.
- **ξ(ᴬ_ZX) = El(X)/A > 0** (encadré, symbole ξ / ℰ). Exemple : 10/7 ≈ 1,4 MeV/nucléon.
- Bilan (colonne de droite) : Δm(réaction) = Σm(produits) − Σm(réactifs) < 0 ; ΔE = Δm·c² < 0 (« d'un seul noyau ») ; **E_lib = |ΔE| > 0** ; en rose ΔE = ΣEl − ΣEl (indices peu lisibles ; les applications montrent qu'il s'agit de ΣEl(réactifs) − ΣEl(produits)). **Sur le tableau, les indices des deux sommes sont écrits avec des lettres peu claires et dans un ordre qui semble s'inverser d'une ligne à l'autre : source de confusion.**
- Applications par El : α : ΔE = El(X) − [El(Y) + El(He)] ; fission : ΔE = El(U) − [El(Sr) + El(Xe)] (le neutron ne compte pas).
- Masse donnée : N = m·N_A/M ; ΔE_T = N·ΔE (|ΔE_T| = |ΔE|·N).
- Réacteur : rendement r = E_él / |ΔE_T|.

  - « ΔE serait positif si on le calcule par les énergies de liaison ? » → Non : ΔE = ΣEl(réactifs) − ΣEl(produits) ; les produits sont plus liés (ΣEl plus grand), donc ΔE < 0, le même signe que Δm·c².
  - « L'énergie de liaison existe-t-elle pour les noyaux instables ? » → Oui, tout noyau (sauf ¹H) a un Δm > 0 et une El > 0 ; l'instabilité se lit sur El/A relativement faible, pas sur l'absence d'El.
