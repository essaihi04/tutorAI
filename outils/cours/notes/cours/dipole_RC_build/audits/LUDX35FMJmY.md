## Rappels du tronc commun / 1re

## Définitions telles qu'écrites
- **Condensateur** : seulement le symbole + « isolant » (en arabe, flèche vers l'espace entre les traits) + « Armatures » ; pas de phrase de définition écrite.
- **Condensateur non chargé** : « غير مشحون » abrégé « N.ch », défini par q_A = 0, q_B = 0, U_c = 0.
- **Charge** (colonne « charge • K fermé ») : « e⁻ M^t » (mouvement des électrons), I ≠ 0 ; « A : se charge, q_A < 0 » ; « B : … q_B > 0 » ; **(q_A = −q_B)** ; |q| ↗ ; U_c ↗ ; puis « sat : U_c = E = cte ».
- **Capacité** : « C : capacité du cond. ; C > 0 ; en Farad (F) ».
- **Charge q** : celle de l'armature par laquelle le courant (choisi positif) **entre** ; q > 0 sur l'armature notée + du dessin.
- **Régime transitoire / permanent, échelon, constante de temps** : **pas employés** ; seul le mot « sat(uration) » pour l'état final.

## Formules telles qu'écrites
- **i = dq/dt** (encadré) — avec en dessous : « charge : q ↗ → dq/dt > 0 → i > 0 » ; « déch : q ↘ → dq/dt < 0 (i < 0) ».
- **q = C . U_c** (grand encadré rouge, trois astérisques dans la marge = très important) ; sous chaque lettre son unité : q en C (coulomb), U_c en V, d'où **C/V = F** ; exemple « C = 2 F = 2 C/V ».
- **Sous-multiples** : µF = 10⁻⁶ F, 1 nF = 10⁻⁹ F, 1 pF = 10⁻¹² F.
- **Série** : « q = q₁ = q₂ » ; « 1/Céq = 1/C₁ + 1/C₂ → Céq = C₁C₂/(C₁+C₂) = 1,2 µF » (C₁ = 2 µF ; la 2ᵉ valeur est peu lisible, 3 µF est cohérent avec le résultat).
- **Parallèle** : « Céq = C₁ + C₂ » et « q = q₁ + q₂ ».
- **Énergie** : encadré **« E_e(C) = 1/(2C)·q² = ½·C·U_c² »**, puis « q = C·U_c » en dessous pour justifier le passage. Notation : **E_e** (indice e), pas W_e ni ξ.
- Équation différentielle, solution, τ = RC, i(t), u_R(t) : **absents** de cette vidéo.

## Ce sur quoi il insiste
- **Code couleur** fixé au tableau : « — charge » en **rouge**, « — déch » en **bleu** ; tout ce qui concerne la charge (flèche i > 0, signes) en rouge, la décharge en bleu.
- **Choix du sens positif** : « on ch(oisit) charge (+) » → i > 0 en charge, i < 0 en décharge ; le courant positif **entre par l'armature +q** ; flèche U_c dessinée vers cette armature (convention récepteur, « CV : récep »).
- **q_A = −q_B** et |q| : la charge du condensateur est celle d'une armature, pas la somme.
- **Pourquoi le courant s'arrête** : à saturation U_c = E − r·I avec I = 0 → U_c = E (il barre r·I).
- Les trois relations de base numérotées (1)(2)(3) préparées pour la suite (équation différentielle).
- Les astérisques en marge marquent ce qui « tombe » (q = C·U_c). Sans audio, aucune phrase « كتطيح فالوطني » ni session d'examen nationale citée n'a pu être relevée.

## Faux, approximations, hors programme
- Rien de hors programme (ni régime sinusoïdal, ni filtres, ni Laplace).
- À ne pas répéter tel quel : « A : se charge q_A < 0 » (dire « l'armature A porte −q ») ; « I = Q/Δt » barré n'est pas faux mais limité au courant constant — le dire ainsi. Le dessin de l'aiguille de (V) « qui monte jusqu'à E » est qualitatif (pas d'échelle de temps).
- La définition du condensateur n'est jamais écrite en phrase ; le cadre attend « deux conducteurs (armatures) séparés par un isolant ».
- Le titre annonce « Dipôle RC : charge/décharge » mais la vidéo s'arrête avant l'étude du dipôle RC (équation différentielle, τ) : à ne pas compter comme couverture de ces notions.

## Ce que notre cours doit lui prendre
1. **L'ordre « appareils avant formules »** : montage avec (A) en série et (V) en dérivation, K ouvert (tout à zéro) → K fermé : l'aiguille de (A) dévie puis revient, celle de (V) monte jusqu'à E → c'est la définition vivante de la charge. Idéal pour une simulation à la craie à deux cadrans.
2. **Les électrons dessinés** qui quittent B et s'entassent sur A (signes − et +), puis reviennent par D en décharge : la meilleure image de « q_A = −q_B » et du courant qui s'inverse.
3. **Le code couleur rouge = charge / bleu = décharge**, gardé du début à la fin, et i > 0 / i < 0 selon le sens choisi.
4. **Le passage I = Q/Δt (barré) → i = lim Δq/Δt = dq/dt** puis le tableau « q ↗ ⇒ dq/dt > 0 ⇒ i > 0 ; q ↘ ⇒ dq/dt < 0 ⇒ i < 0 ».
5. **« U_c = E − r·I » avec r·I barré** pour expliquer la saturation (I = 0 ⇒ U_c = E).
6. **Les unités écrites sous chaque lettre de q = C·U_c** (C, V → F) et les sous-multiples µ/n/p.
7. Écriture de l'énergie **E_e = q²/(2C) = ½·C·u_C²** avec q = C·u_C juste dessous.
