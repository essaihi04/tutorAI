Découvrons l’EXAO avec ton tuteur

L’EXAO est une expérimentation assistée par ordinateur : des sondes mesurent O₂ et CO₂, l’interface transforme leurs signaux et l’ordinateur trace les courbes en temps réel.

  1. Sondes : mesurent les gaz dans le bioréacteur.
  2. Interface EXAO : relie les capteurs à l’ordinateur.
  3. Ordinateur : affiche et enregistre les courbes.
